# Kummisetä – verkkokaupan ulkoasu

Luonnosvaiheen tyylisuunnat Divari & Antikvariaatti Kummisedän Ecwid-verkkokaupalle.

- `index.html` – suuntien valinta
- `suunta-a.html` – A · Kirjastokortti
- `suunta-b.html` – B · Kyltti

Tyyli on määritelty CSS-muuttujina (`:root`), joten suunnat jakavat saman rakenteen. Tuotekuvat ovat esimerkkejä.
